# 5.3 — `architecture-audit`, the near-move

**Date:** 2026-08-03
**Gate:** 9/9. Preservation: 8/8. 15 files, 108K.
**Result:** the direction doc's "already deliberately portable" claim **holds** — with one exception it
didn't mention.

## The claim, verified rather than trusted

5.1 and 5.2 both taught that a claim about a file needs checking against the file. So before moving
this, I tested the portability assertion directly:

- **Both repos' copies are byte-identical** — a true free move, no reconciliation.
- **Zero client names, absolute paths, or hostnames.**
- **Zero hardcoded project-shaped paths** — no `src/<Assembly>` patterns anywhere.
- **The four bash scripts make no path or project-shape assumptions.**

That is a genuinely different result from every other extraction in this phase. It was written portable
on purpose, and it shows. The doc was right to call it the model for pack skills, and its
`SKILL.md` + `references/` + `scripts/` + `assets/` + `evals/` layout is what the other pack skills have
been imitating since 5.1.

## The one project fact the doc didn't mention

It hardcoded its report destination — `_audits/<YYYY-MM-DD>-<slug>.md`, in two places plus an eval
fixture. That is a workspace path, and the new layout puts committed audits under `docs/audits/`.

Now deferred to the `workflow` skill's layout, and the skill gained the artifact-disposition rule the
spine defines for anything that produces a report: **ask whether the output is durable or temporal**,
so location enforces commit status rather than being a separate thing to remember. Plus a note that an
undated audit gets mistaken for current truth — the reason the date is in the filename.

## Two things I nearly shipped broken

**A patch on a patch.** My first substitution replaced a phrase mid-sentence, and the surrounding text
continued in a way that left the line reading *"…per the `workflow` skill's layout by default (the skill
creates `_audits/` if absent…"* — duplicated clause, and the old path still there. Caught by grepping
for the thing I had just supposedly removed, not by the gate. **When a substitution lands mid-sentence,
rewrite the sentence whole** rather than patching around what the replacement left behind.

**A stale eval fixture.** `evals/evals.json` asserted `Report saved to _audits/<date>-this-repo.md` as
expected output. Left alone, the skill's own eval would have failed against the corrected skill — and
the failure would have looked like a regression in the skill rather than a stale expectation. Updated
alongside.

That second one generalizes: **a skill that ships its own tests has two places to change, and the test
is the one that fails later and confusingly.** Worth checking whenever a pack skill's behavior is
adjusted.
