## Not a merge — a reconciliation

The demo project had already shipped the `reverse-spec` absorption, so this was never the merge
the plan originally scoped. It was reconciling two versions to one, with the demo's as the model.
All four of the merge spec's open questions were already answered by the shipped implementation

of the file rather than re-decided.

Guard`, was renamed rather than dropped — confirmed, nothing lost.

## Method fix: line-based grep gives false negatives

Preservation checking flagged three items as LOST that were all present — "Example Mapping",
"Test assertions are the strongest", "masquerading". The first two were hard-wrapped across a line
break; the third correctly lives in `workflow` and `/spec`, where `/feature`'s Guard defers.

Extracted files are hard-wrapped at 100 columns, so *any* probe long enough to matter has a good
chance of straddling a newline. Line-based grep was structurally unsuited to this check and would
have kept producing noise for four more increments — or worse, trained me to wave off real losses
as "probably just wrapping."

Fixed with `scripts/check-preserved.py`, which normalizes whitespace and strips markdown emphasis
before matching. Re-ran: 17/17.
